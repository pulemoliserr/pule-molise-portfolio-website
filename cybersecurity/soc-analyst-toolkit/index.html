SOC Analyst Toolkit

A web app that turns everyday analyst tasks into working tools: SQL login investigation, tcpdump triage, IP allow-list updates and Linux permission checks.

S

Situation

My course projects showed I could analyse logs and packet captures, but only on paper. A recruiter can't see those skills in action in a PDF, so I wanted something they could click on and try.

T

Task

Combine several exercises into one deployable app that demonstrates core SOC tasks on realistic synthetic data.

A

Action

  • Login investigation: filter controls generate SQL live against a synthetic SQLite log database that contains a planted brute-force incident. There is also a read-only box for custom queries.
  • tcpdump triage: parses a pasted capture and flags ICMP port-unreachable errors (DNS outages) and SYN floods, by comparing SYN packets with completed handshakes.
  • Allow-list updater: validates IP addresses, removes revoked ones and offers the updated file for download.
  • Linux permissions: a chmod calculator that converts between symbolic and octal and warns about least-privilege problems.
  • Restricted the custom SQL box to a single read-only SELECT statement, and tested the app headlessly with Streamlit's AppTest.
R

Result

  • Recruiters can try four SOC skills from a single link.
  • The triage tool correctly diagnoses the DNS outage from my network analysis project and flags a SYN flood of 60 SYNs with 0 completed handshakes.
  • The brute-force alert surfaces the planted incident, 34 failed logins from one IP followed by a successful one, which is exactly the pattern an analyst should escalate.
