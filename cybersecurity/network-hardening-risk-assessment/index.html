Security Risk Assessment: Network Hardening

After a data breach at a social media company, assessed four network vulnerabilities and recommended hardening measures based on NIST guidance.

S

Situation

A social media organisation suffered a breach that exposed customers' names and addresses. An inspection found shared passwords, a default database admin password, firewalls without rules, and no multi-factor authentication.

T

Task

Write a security risk assessment that recommends up to three hardening methods and explains how they address each vulnerability.

A

Action

  • Assessed how each vulnerability could lead to another breach.
  • Selected password policies, firewall maintenance and multi-factor authentication, and mapped each one to the vulnerabilities it fixes.
  • Aligned the password policy with NIST SP 800-63B: favour length over complexity rules, screen out breached passwords, and change passwords only after a compromise, not on a schedule.
  • Recommended default-deny firewall rules including outbound filtering, and an MFA rollout starting with administrators.
R

Result

  • All four vulnerabilities are covered by three low-cost measures, with a clear priority order and review schedule.
  • Showed how layering identity and network controls gives defence in depth.
