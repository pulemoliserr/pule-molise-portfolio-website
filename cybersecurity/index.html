Cybersecurity Projects

Detection engineering, cloud security, incident response and GRC work. I completed the Google Cybersecurity Professional Certificate and the Google Cloud Cybersecurity Certificate. The 4 personal projects build on them; the case studies are based on the certificate's scenarios. Every project is written up with the S.T.A.R. method: Situation, Task, Action, Result.

Personal project Detection Engineering

Detection-as-Code: Tested Sigma Rules

16 Sigma detection rules mapped to MITRE ATT&CK, each tested automatically against attack and benign log events.
Personal project Cloud Security · Google Cloud

Cloud Security: Hardening a Misconfigured GCP Deployment

A Google Cloud deployment written twice in Terraform, first with 8 common misconfigurations and then hardened. Failed security checks went from 31 to 0.
Personal project Vulnerability Management · R Shiny

KEV Tracker: Known Exploited Vulnerabilities Dashboard

Interactive dashboard of CISA's catalog of vulnerabilities exploited in real attacks, showing which vendors, weaknesses and patch deadlines matter most.
Personal project Security Tooling · Streamlit

SOC Analyst Toolkit

A web app that turns everyday analyst tasks into working tools: SQL login investigation, tcpdump triage, IP allow-list updates and Linux permission checks.
Case study GRC · Compliance Audit

Botium Toys: Internal Security Audit

Assessed a retailer's security program against 14 controls and the PCI DSS, GDPR and SOC 2 requirements, and wrote a prioritised remediation plan.
Case study Network Analysis · tcpdump

Network Traffic Analysis: DNS Service Outage

Diagnosed a website outage from a tcpdump capture and traced it to a DNS server that had stopped answering on UDP port 53.
Case study Incident Response · Network

Incident Report: SYN Flood DoS Attack

Identified a SYN flood denial-of-service attack from a packet capture, explained it to management and recommended mitigations.
Case study Risk Assessment · Hardening

Security Risk Assessment: Network Hardening

After a data breach at a social media company, assessed four network vulnerabilities and recommended hardening measures based on NIST guidance.
Case study Incident Response · Web

Incident Report: Website Compromise via Brute Force

Traced a malicious redirect on a recipe website back to a brute-forced admin account, and recommended controls to prevent it from happening again.
Case study Incident Analysis · NIST CSF

Incident Analysis: ICMP Flood DDoS with NIST CSF

Used the NIST Cybersecurity Framework to turn a DDoS attack that took a network down for two hours into a security improvement plan.
Case study Linux · Least Privilege

Linux: Securing File Permissions

Audited and corrected file permissions on a research team's Linux directory to enforce least privilege.
Case study SQL · Log Investigation

SQL: Filtering Data for Security Investigations

Used SQL filters to investigate suspicious logins and to list exactly which machines needed security updates.
Case study Python · Automation

Python: Automating an IP Allow-List Update

Automated updating an IP allow list in Python, then fixed a hidden bug and added input validation and unit tests.
