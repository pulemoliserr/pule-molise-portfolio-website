Network Traffic Analysis: DNS Service Outage

Diagnosed a website outage from a tcpdump capture and traced it to a DNS server that had stopped answering on UDP port 53.

S

Situation

Customers of a client reported that www.yummyrecipesforme.com wouldn't load and showed the error "destination port unreachable".

T

Task

Find out which network protocol and service were failing, and document the incident for the security engineers handling the fix.

A

Action

  • Reproduced the error, then captured the traffic with tcpdump while loading the site.
  • Matched each outgoing DNS query to its response, and recorded source and destination, ports and timestamps.
  • Worked through the evidence layer by layer. The ICMP reply showed the DNS host was reachable, while the port-unreachable code pointed to a failed service.
  • Ranked the likely causes and escalated with concrete next steps.
R

Result

  • Root cause: the DNS server at 203.0.113.2 was up, but no service was listening on UDP port 53. All three queries over about four minutes got an ICMP port-unreachable reply, so the website itself was probably fine.
  • Recommended checking and restarting the DNS service, reviewing firewall changes, adding a secondary DNS server, and monitoring DNS availability.
